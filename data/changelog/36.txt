goThoom 36 adds support for Clan Lord v1497.

New and improved:
- Added a setup wizard for controls, status bars, bubbles, name tags, graphics, and performance. It includes a live offline graphics preview so you can see changes immediately.
- Added a built-in legacy macro library, macro editor, and improved support for script function hotkeys.
- Movie recording can now be started before connecting or while already playing, and recordings remain compatible with the existing movie format.
- Added Settings → Text Colors for Say, Whisper, Yell, Think, Action, Ponder, Narration, Monster, and System messages.
- Added dark speech bubbles and name tags, enabled by default.
- Added searchable Players and Inventory windows, selectable/copyable text in Chat and Console, and optional subtle alternating rows in Chat, Console, Inventory, and Players.
- Added compact sharing-status icons in the Players window, including one-way and mutual sharing indicators.
- The Clan Lord window title now includes the active character name.

Defaults and options:
- Chat and Console timestamps, game notifications, and notification beeps now default to on.
- Throttle Repeated Sounds defaults to on.
- Your own name tag is hidden by default, and name-tag frames appear only for players with a label color (cleaner)
- Window-pinning buttons default to off and can be enabled in Settings.

Fixes:
- Fixed recorded movies starting without initial player, clothing, scenery, or other world details.
- Fixed a visible scene jump when a movie loops.
- Restored copy and paste after the recent library update.
- Fixed anonymous thoughts from blocked or ignored players still appearing.
- Fixed several music playback race conditions and script function hotkeys being sent as hidden server commands.
- Newer locally installed Clan Lord data no longer triggers the untested-version warning.

Performance:
- Reduced rendering allocations and repeated work for smoother play, especially in busy scenes.
- Improved motion smoothing for large, semi-transparent moving sprites such as clouds.
- Reduced unnecessary image decoding, hover checks, and repeated chat-trigger text processing.
