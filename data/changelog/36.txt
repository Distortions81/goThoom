goThoom 36 adds support for Clan Lord v1497.

New and improved:
- Added a friendly setup wizard for controls, status bars, bubbles, name tags, graphics, and performance. Its controls reflect your existing settings and changes appear immediately in the live offline preview.
- Added a live graphics preview to the setup wizard. A short Clan Lord recording loops through the real game renderer so you can see dithering, artwork upscaling, motion smoothing, and shader lighting as you change them if you aren't clanning.
- Movie recording now starts correctly whether it is armed before connecting or started while already playing. New recordings remain compatible with the existing movie format.
- Alternate networking mode and timing choices are now remembered between sessions.
- Added support for both "Mouse4" and "Mouse 4" hotkey spellings, with clearer scripting help for function hotkeys.
- New installs now enable fading obscuring artwork, dither blending, smooth movement, character and world animation blending, shader lighting, and sprite gamma correction by default.
- Launched the new project website at https://gothoom.m45sci.xyz/ and moved game-asset downloads to its dedicated mirror.

Fixes:
- Fixed recorded movies starting without the player, clothing, scenery, or other initial world details.
- Fixed the scene sliding between the end and beginning when a movie loops.
- Restored copy and paste after the recent library update.
- Fixed script function hotkeys being sent as hidden server commands instead of running locally.
- Fixed anonymous thoughts from blocked or ignored players still appearing.
- Fixed several music playback race conditions.
- Newer locally installed Clan Lord data no longer triggers the untested-version warning.

Performance:
- Reduced rendering allocations and repeated work for smoother play, especially in busy scenes.
- Made object-pinning lookups about 9.8x faster in dense scenes.
- Made image dithering cleanup about 12% faster while using about 85% less temporary memory.
- Reduced unnecessary image decoding, hover checks, and repeated chat-trigger text processing.

For source builds, goThoom now uses Go 1.26.6, Ebitengine 2.9.10, and refreshed dependencies. Automated dependency checks and additional regression tests and benchmarks were also added.
