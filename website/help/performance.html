Choose the problem before changing settings

A low frame rate, a one-time loading pause, and a picture you do not like need different adjustments. Open Settings → Display → Show FPS, then compare changes in the same scene at the same game-window size. Keep the client focused during a comparison so background power saving does not change the result.

Make a comparison you can undo

  1. Choose a familiar location or use the same point in a movie recording for repeatable visual comparisons.
  2. Note the current preset and the option you plan to change. A screenshot of its settings page can help restore your starting point.
  3. Change one setting and inspect the same scene. For loading behavior, also check a new room and a room you revisit.
  4. Keep the change if it improves the thing you are trying to fix. Otherwise restore it before testing another option.

Changing artwork processing can clear its cached results. The first draw afterward may include rebuilding work; distinguish that temporary pause from the behavior after the scene has settled.

Presets and the effects master switch

Settings → Performance → Quality preset provides a starting set of graphics choices. The setup wizard’s check chooses Default or iGPU Graphics. Choose the preset before individual tuning: applying another preset can change several options at once.

Enhanced visual effects controls lighting, animation blending, replacement effects, and faster shadows together. Turning it off preserves the individual choices while disabling the affected features. This makes it useful for a quick comparison. If a feature’s control is greyed out, check its master switch before assuming that the individual setting was lost.

Profiles can make your choices character-specific. A different saved character may load different graphics settings when Keep settings separate is enabled. Read about character profiles before diagnosing a change that only happens when you switch characters.

Artwork resolution, edges, and color

Artwork scale override controls the resolution of prepared artwork textures. Its default is 2×, and the control offers up to 4×. Resizing the game window does not change that setting. More detailed textures require more graphics memory, even if you display them in a small game pane.

Artwork upscale style changes the treatment of the original pixels. Crisp preserves hard boundaries; smoother styles blend more neighboring pixels. Compare small faces, equipment, and high-contrast scenery rather than judging only a large flat area.

Choose a visual direction

  • For a sharper, more classic look: start with a crisper upscale style and compare Pixel-art scaling. If the picture still appears softened, turn off Blend Image Dithering and compare the result.
  • For gentler edges: compare the smoother styles while standing still. Then walk through the scene; a treatment you like in a still image may look different in motion.
  • If artwork looks washed out: compare Enable Sprite Gamma Correction before adjusting several brightness settings. Sprite Gamma describes the source artwork’s brightness encoding; Monitor Gamma describes the target response. They are not two independent brightness boosts.

Blend Image Dithering processes the artwork’s alternating pixel patterns. Its Denoise strength and Sharpness controls alter that treatment; judge both the intended smoothing and any fine detail you want to keep.

See characters behind scenery

Fade objects obscuring mobiles makes obstructing artwork less opaque. Its opacity value controls how much of the object remains visible while faded. This changes visibility, not collision: being able to see through an object does not mean your character can walk through it.

Separate movement smoothing from pose blending

Smooth Motion interpolates movement between updates. Character Animation Blending blends changing character poses, and World Animation Blending handles changing world imagery. You can like smooth travel while preferring an immediate change of pose.

  • If travel looks jerky, compare Smooth Motion first.
  • If a moving sprite seems to shimmer, compare Subpixel movement. It permits positions between screen pixels; turning it off places sprites on whole pixels.
  • If changing poses leave a smeared appearance, reduce the relevant blend duration or disable that kind of animation blending.
  • If small moving pictures lag visually behind the rest of the scene, compare Smooth small moving objects. It depends on Smooth Motion and only attempts to smooth eligible small sprites.

These controls change the displayed transition between received states. They do not make the server send updates more often or remove a delay in receiving them.

Lighting and shadows

Use Lighting & Effects to compare scene lighting and character shadows separately. Light strength, glow, and flame flicker affect appearance; turning off a whole effect is a clearer first comparison when diagnosing its rendering cost.

  1. Compare Lighting Effects in the same scene, including the same night conditions where possible.
  2. Compare Character Shadows separately. Window Shadows belongs to the UI windows, so changing it will not remove shadows under characters.
  3. Try Faster Character Shadows if you want to compare the alternative shadow path. Judge both the resulting image and drawing performance.
  4. Leave Experimental choices for separate comparisons after you have a stable setup. Replacement effects and mobile light-cone shadows are not required to use the client.

If options here seem inactive, check Enhanced visual effects at the top of Performance. To make a dark scene more readable without changing every lighting option, also inspect Settings → World → Max Night Level.

Loading pauses and memory use

Batch room artwork loading prepares missing room artwork in one pause instead of spreading its first-use work across several frames. It changes when you experience that work. Compare room entry and the movement immediately afterward, not just an FPS reading while standing still.

Choose how much artwork to keep ready

The Sprite cache presets range from Minimal through Compact, Balanced, Generous, and Maximum. Balanced is the default. A smaller reserve leaves room for other applications but can require artwork to reload more often. A larger reserve can help when revisiting areas, if the machine has room for it.

The reserve scales with artwork resolution. For example, Balanced reserves 512 MiB at 2×, 1,152 MiB at 3×, and 2 GiB at 4×. Doubling the texture dimensions uses four times the area, so increasing artwork resolution and cache size together can be a large memory change.

This is not a ceiling on total graphics memory: the scene, interface, and other rendering resources also need memory. Read the reserve explanation below the selector and restart after changing the preset to rebuild it.

Recognize sound-loading pauses

Precache Sounds spends roughly 300 MB of additional RAM to avoid decoding a sound on its first playback. Consider it when a hitch coincides with a sound first being heard. It is a separate tradeoff from retaining artwork in graphics memory.

Use activity dots as clues

Show asset activity dots distinguishes artwork decoding/processing in green, audio decoding in amber, and GPU artwork upload in red. A dot tells you work is happening; it does not, by itself, establish the cause of a slowdown. Compare its timing with the pause you are investigating.

Potato GPU (4096px Limit) is the compatibility option for devices constrained by large textures. It is not a general promise that every slow machine will run faster. For continued problems, include the device, artwork scale, cache preset, and observed symptom in your report.

Frame-rate limits and background behavior

Power save in background reduces drawing while the client is unfocused. Always power save applies the power-saving limit even while focused. Both use the Power-save FPS value.

VSync - Limit FPS relates drawing to the display’s refresh behavior. Disabling it can increase drawing work and power use without changing the game server’s timing. Do not interpret a deliberately capped rate as proof that your graphics settings are too demanding.

  1. If the rate drops only when you switch applications, check the background setting.
  2. If it stays capped while you play, check Always power save and Power-save FPS.
  3. If the cap matches the display’s refresh rate, check VSync before reducing visual quality.
  4. After testing, restore the power settings you want for ordinary use.

Restore a usable picture

Open Settings → Performance → Quality preset and choose a preset to restore a coordinated set of graphics settings. Use this when the picture becomes difficult to read after experimenting with individual options. Once it looks comfortable again, make any further adjustments one at a time.

For a report, record the client version, operating system, graphics device, window size, UI scale, quality preset, and the specific settings that reproduce the problem. Include whether it occurs on first room entry, throughout a scene, only during movement, or only when unfocused. The diagnostics walkthrough explains screenshots and logs.
