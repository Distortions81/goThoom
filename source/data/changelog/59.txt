goThoom 59 changes since test58.

Multi-session:
- Open four independent session views from the toolbar.
- Click a session view to select it and direct movement, commands, hotkeys, scripts, Inventory, Players, Chat, and Console to that character.
- Keep every session's network activity, macros, enabled Go scripts, notifications, sound effects, and visual script effects isolated while background sessions continue running. Global scripts receive an independent runtime for every connected character, and character-scoped scripts run only in matching sessions.
- Choose one session as the shared music source and switch it without mixing or resuming another character's tune.
- Connect directly inside each session view with the normal saved-character list, character editor, server list, and password prompt, follow connection progress and errors there, or use the small bottom-right logout icon in each connected view. Return to single-session mode from the toolbar after every session disconnects.
- Use movable session views with the normal freeform Window Layout setting, or a fixed 2×2 grid inside the existing game area with tiled Window Layout. The selected session has the theme accent title bar and, when tiled, an accent outline. The client restores freeform positions, selected session, and music source the next time multi-session opens.
- Prepare newly encountered area artwork independently for each session, so matching frame counters in other views cannot force slow one-at-a-time asset loading.

Bard music:
- Match the classic client instrument program and percussion behavior, including the supported instrument aliases and octave handling.
