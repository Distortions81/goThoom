goThoom 59 changes since test58.

Multi-session:
- Open up to ten independent character tabs above one shared game view. Use + to add a tab and its X, with confirmation, to disconnect and close it.
- Switch tabs with the mouse or the customizable Ctrl-1 through Ctrl-9 and Ctrl-0 hotkeys. Movement, commands, hotkeys, scripts, Inventory, Players, Chat, and Console follow the selected character.
- Render only the selected tab while every background session continues network processing, macros, enabled Go scripts, recording, and other session-owned work.
- Play sound effects only from the selected tab. Track complete bard performances in every session and resume a still-active performance at its current time when its tab is selected.
- Connect directly inside the shared game view with the normal saved-character list, character editor, server list, and password prompt, and use the small bottom-right logout icon for the selected connection.
- Restore open tabs and the selected session on the next launch.
- Keep every session's network activity, macros, enabled Go scripts, notifications, and visual script effects isolated. Global scripts receive an independent runtime for every connected character, and character-scoped scripts run only in matching sessions.
- Prepare newly encountered area artwork independently for each session, so matching frame counters in other views cannot force slow one-at-a-time asset loading.
- Keep each session's time of day, indoor/outdoor lighting, shadows, lighting preparation, and transitions independent.
- Connect with the built-in demo character from any disconnected session tab.
- Inspect and control the selected character's actual Go-script runtime in the shared Scripts window, including its status, errors, registrations, settings, commands, and key bindings.
- Reconnect each unexpectedly disconnected session independently with cancellable backoff, while cleanly joining every connection supervisor during logout and shutdown.
- Record sessions independently and keep a separate persistent Text Log for each slot, including when more than one session uses the same character name.

Bard music:
- Match the classic client instrument program and percussion behavior, including the supported instrument aliases and octave handling.
