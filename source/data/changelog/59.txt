goThoom 59 changes since test58.

Movie playback:
- Movies open in their own labeled session tab, keeping their scene, messages, lighting, and bard music separate while you switch among live character tabs.
- Closing Movie Controls or the movie tab ends playback, removes the temporary tab, and returns to the previously selected session.

Graphics:
- Removed thin background-colored seams between adjacent ground tiles when artwork upscaling is disabled.
- Reduced lighting and custom-color rendering overhead, especially in busy scenes.
- Corrected custom character colors in older recordings where a character supplies fewer colors than the artwork supports.

Audio:
- Improved enhanced game sounds so ambience keeps its intended character and simultaneous effects retain consistent volume.
- Optionally spread sound effects arriving in the same game update across a short, adjustable interval so each effect remains distinct. This is enabled by default.
- New settings start with game effects at full volume and bard music at one-third volume for a clearer initial mix.

Interface:
- Improved tab highlights throughout the client, with a clearer selected-tab indicator.
- Upgrades now offer to apply the current recommended graphics, loading, sound, power-saving, and speech-bubble settings when your choices differ; settings outside that list remain unchanged.
- Hand-edited and older numeric settings are kept within the ranges supported by the current controls instead of producing unusable layouts, rendering, audio, or timing values.

Performance:
- Power saving now accounts for time already spent rendering or waiting for the display before sleeping, and its target can be set from 1 to 250 FPS.
- A separate, default-on 250 FPS limit prevents unbounded rendering when VSync is off; active power saving uses its chosen power-save limit instead.
- Upgrade recommendations account for available system memory and the GPU texture-size limit when suggesting sound precaching, sprite-cache size, and GPU compatibility mode.

Desktop:
- Restored compatibility with macOS 13 Ventura by updating Ebitengine to v2.10.2.

Documentation:
- Refreshed the built-in guide and online manual to match the current interface, with updated screenshots and task-focused guidance for session tabs, gamepads, local streaming, file locations, hotkeys, scripts, and performance settings.
