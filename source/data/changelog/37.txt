goThoom 37 changes since test36.

New and improved:
- Added Character Shadows, enabled by default. Upright characters cast sun-directed projected shadows while creatures, boats, and prone characters use inexpensive drop shadows.
- Added Accurate Character Shadows, enabled by default. Overlapping character shadows are combined before darkening the scene so crowded groups do not become excessively dark.
- Added a Character Shadow Darkness slider ranging from barely visible to very dark, with the existing appearance as its default.
- Character shadows use each matching animation frame's original alpha directly, with no blur, softness gradient, opacity gradient, or per-frame normalization.
- Character shadow direction, mirroring, length, and low-sun behavior follow the classic client's projection model.
- Light and dark casters now respect their lighting-plane metadata while retaining the single-pass shader path.
- Added support for `kPictDefFlagOnlyAttackPosesLit`, `kPictDefFlagLightFlicker`, and random-animation picture definitions.
- Random-animation scenery instances now select stable independent frames instead of animating every copy in lockstep.
- Flickering lights use smoothly changing flame-like position, brightness, and radius variation. The effect and its strength are adjustable in Quality Settings.
- Added GPU pixel-art artwork upscaling with Off, Crisp, Balanced, Smooth, and Ultra Smooth styles. Ultra Smooth blends reconstructed edge pixels without sampling across sprite or tile boundaries.
- Artwork upscaling is now selectable in both Quality Settings and the Setup Wizard.
- Thought and ponder bubble shapes are composited into one mask before opacity is applied, preventing overlapping parts from becoming darker than the rest of the bubble.
- Blend Image Dithering now uses color-aware Sobel edge protection with palette smoothing for both regular and irregular dithering, preserving hard and diagonal edges, one-pixel lines, corners, isolated details, and transparency boundaries.
- Settings, Quality, Advanced, Notification, Bubble, and Debug configuration windows now use clearer named sections and spacing so related controls are easier to find.
- Settings files now use categorized version 4 JSON with readable lower-case option names. Existing version 1-3 settings migrate automatically without losing values.
- Added an iGPU / Low-VRAM (Potato GPU) quality preset and clarified its name and purpose.
- The demo-character login flow now handles required data updates and repeated server challenges automatically.
- Legacy macros now receive the real input-box selection through `@textsel` while editing or invoking a macro.
- Added a synthetic offline Setup Wizard scene with characters and scenery tailored to preview daytime, nighttime, indoor, glow, shadow, animation-blending, and motion-smoothing settings.
- Added Modern and Classic player-health name displays. Modern uses a configurable fixed-width color bar above or below the name; Classic restores the original colored name background.
- The Players window now reports the classic online/offline state instead of estimating how long ago a character was seen.

Defaults and options:
- Flame-style light flicker, Character Shadows, Accurate Character Shadows, and artwork upscaling default to on.
- The default game artwork scale is now 4x and the default upscale style is Ultra Smooth.
- Blend Image Dithering now defaults to off with Sharpness 10 and Strength 35, remains available in the Setup Wizard and Quality Settings, and is no longer changed by quality presets.
- iGPU / Low-VRAM mode bypasses costly shader lighting, detailed shadow compositing, animation blending, and other expensive effects, while retaining sharp artwork upscaling at up to 2x.
- Stereo Music now defaults to off.
- When Stereo Music is enabled, bard parts are spread across a maximum 40% stereo field instead of 70%.
- Modern player-health bars default above the name at three pixels thick, remain hidden at full health, and the player's own name tag is visible by default.
- Updated the default application and panel geometry to the current desktop layout; resetting window positions restores it while still clamping safely on smaller screens.

Fixes:
- Restored clearly visible ponder-bubble animation after compositing its overlapping shapes into a single-opacity mask.
- Stabilized character-shadow attachment and treatment across players and animation frames by using the same fixed logical cell and ground edge as character rendering; shadows follow the matching walk-cycle frame without moving their treatment field.
- Character shadows use the exact current walk-cycle frame without animation crossfading, avoiding intermediate alpha textures that made their darkness pulse while walking or idle.
- Kept speech-bubble text independent of the artwork supersampling scale and adjusted the default interface font sizes for clearer bubbles and more compact lists and names.
- New installations now enable sound precaching with at least 4 GiB of system RAM and artwork precaching with at least 8 GiB; both remain off by default in browsers or when memory cannot be detected.
- Added a repeatable setup-wizard graphics benchmark using the real lighting and artwork-upscale shaders. Its result dialog clearly labels and can apply the recommended Full Quality or iGPU / Low-VRAM preset, and the sustained low-FPS warning now offers the complete low-resource preset.
- Synchronized image-cache invalidation with background precaching so quality changes cannot repopulate caches with images being cleared.
- Restored the compact pre-tuning radius for emitted light glows so nearby artwork stays clear instead of looking broadly blurred.
- Expanded dark-caster coverage, reduced dead dark-caster intensity, and stopped fully off-screen lighting sources from consuming shader capacity.
- Fixed mostly-offscreen clouds losing motion smoothing; ordinary edge objects still use the conservative edge rule.
- Fixed inventory and Players icons sometimes disappearing after a texture-cache clear until the window was resized.
- Fixed picture decoding in v366-and-older movies so lighting, sun angle, and other frame state continue updating during playback.
- Movie seeking now restores night level and sun position from checkpoints, keeping character-shadow direction and length synchronized after scrubbing.
- Fixed inventory wear-location labels extending underneath the list scrollbar.
- Increased the minimum scrollbar thumb size so the window resize corner cannot cover the entire thumb.
- Fixed closing or interacting with a UI window sometimes allowing the same click to reach the game world and accidentally move the player.
- Fixed duplicate login and demo-character requests from competing when buttons were clicked repeatedly.
- Fixed music players sometimes being treated as finished before their first audio callback, which could stop music and produce "audio: player is already closed" errors.
- Fixed streamed music chunk boundaries so synthesizer render blocks are kept intact, reducing audible seams between chunks.
- Music rendering now continues filling its bounded playback queue while a song is playing, after the initial five-second buffer is ready.
- Scoped music-stop commands now close only the matching performer or group stream without disabling the Music mixer setting.
- Character shadows now use the same upscaled sprite source as character rendering. Fallen and lying characters receive a small attached drop shadow instead of an upright sun projection.
- Character and contact-shadow anchors now follow the opaque foot of each sprite, preventing large creatures from appearing to hover above their shadows.
- Contact shadows are suppressed inside another character's or scenery light while ignoring a character's own emitted light.
- Local-light cone cutouts now consider characters throughout the visible glow tail, select up to 32 closest interactions, and ignore lights centered directly on their owner.
- Hover-only name tags remain visible briefly after the cursor leaves, then fade smoothly before returning to the compact health indicator.

Technical changes:
- Moved the Go module and runtime source tree under `source/`; repository-level build scripts and documentation were updated for the new layout.
- Published release builds no longer run for ordinary pushes, and the WebAssembly build is maintained as a separate explicit build script.
- Artwork-upscale caches now distinguish each selected style and are cleared when relevant quality settings change.
- Added regression coverage for settings migration, lighting flags and planes, random animations, character shadows, artwork upscaling, thought-bubble compositing, cache refreshes, music streaming and stopping, scrollbar sizing, UI click ownership, and legacy macro text selection.
