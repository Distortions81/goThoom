goThoom 61 changes since test60.

Movement and networking:
- Direction changes and stopping respond more promptly with motion smoothing on or off. Smoothing off follows classic-client movement behavior; smoothing on preserves short clicks.
- NLSPT adapts more cautiously to slow or unstable connections, using original timing until conditions improve. Movement stays current during connection recovery.

Editors:
- Create and edit legacy macros and Go scripts directly in the client, with syntax highlighting, search, word wrap, clipboard shortcuts, undo/redo, and formatting.
- Check drafts before applying them, then Save & Reload in the selected session. Unsaved drafts are protected when closing editors or quitting.
- Customize syntax colors and editor text size. Editor toolbars wrap to fit narrow windows.
- Edit TTS pronunciation substitutions, color themes, and style themes in Settings. Theme editors include color pickers, transparency previews, and undo support.

Personal notes:
- Tools → Personal Notes stores global or player-specific notes with subjects, tags, and searchable text.
- Filter notes by player or scope. Deleted notes remain recoverable from the user data folder.

Movies and visuals:
- Improved lighting and shadow compatibility with classic-client movies, including the starting state of new recordings.
- Removed automatic fading of objects that cover characters.

Interface:
- Spelling corrections open only when right-clicking an underlined word and dismiss when the pointer moves away.
- Closing the main or last session disconnects and returns it to login while keeping the tab open.
- Floating-window resize handles respond consistently at edges and corners, including beside tiled-window dividers.
- Single-button script toolbars omit redundant group labels, and Text settings group font sizes in two columns.
