goThoom 48 changes since test47.

Networking and Live Stats:
- Added optional Predictive Network Adjustment (PNA). It learns the server's update phase and sends fresh player input shortly before the next expected processing window, using command replies as feedback without delaying input.
- PNA automatically adapts to the measured server update rate, frame jitter, and learned timing boundary. Its adjustable percentage safety margin is session-only; only the PNA on/off choice is saved.
- Meaningful recent packet loss temporarily returns PNA to normal immediate networking. Recovery uses a cooldown and hysteresis to prevent mode flapping; latency, reply time, and jitter remain timing feedback rather than reasons to pause PNA.
- Added a Live Stats window with five-minute graphs for command replies, rolling p95 frame jitter, client FPS, server update rate, decoded cache memory, and estimated GPU texture memory. Graphs show compact legends and independent scales with sensible minimum ranges.
- Expanded the optional toolbar statistics with command reply time, 60-second p95 frame jitter, recent loss, and concise PNA learning, paused, or lead status.
- Added separate recent and whole-session packet-loss figures, server frame interval and rate, PNA phase/lead/safety details, packet totals, and a clear visual warning when PNA is paused.
- Added bounded rotating diagnostic logs under the user data folder's Diagnostics directory, including startup details, the first shutdown reason, and crash stacks. Advanced Settings can open the folder containing the current log and five backups.

Chat bubbles:
- Added default-on overlap prevention for ordinary speech, whispers, thoughts, ponders, yells, and growls. Bubble tails are drawn beneath all bodies so crowded pointers cannot cover text.
- Bubble placement now avoids the full visible shape of ponder waves, yell spikes, and growl spikes. Action and narration boxes remain fixed because their position is meaningful, while other bubbles yield to them.
- Crowded bubbles periodically reconsider their layout and ease smoothly to a new position. Isolated bubbles retain stable placement instead of jumping away and drifting back.
- Bubbles near the top edge move below their speaker when necessary rather than folding their pointer inward or covering the mobile.
- Bubble text wraps toward a natural 2:1 body shape without adding empty aspect-ratio padding. Oversized messages have a bounded body and reduce their font size when needed.
- Named bubbles can reconnect to their speaker by name if the server changes that mobile's descriptor index. Ordinary orphaned bubbles hide while their lifetime continues; yells and thoughts can remain at their last location, and unnamed bubbles never attach to a reused index.
- Modern lifetime sliders are disabled when Classic bubble lifetime is selected.

Rendering, movies, macros, and settings:
- Added a default-off option to interpolate independently moving sprites whose visible animated artwork is no larger than 35 by 35 pixels and moves no more than 64 pixels between updates, such as coins following a mobile. Transparent padding no longer makes a small sprite appear too large for this test.
- Movie seeking now publishes a complete rendered scene about every half second instead of partial intermediate updates, and always leaves a complete final frame. The SEEKING label background now follows the measured text size.
- Image archive exports can optionally emit only frame 0 of each image while retaining the source animation-frame count in metadata. Static sprites omit the redundant _0 filename suffix.
- Fixed an intermittent command-line movie startup race that could close Movie Controls and cleanly shut down the client while startup window state was still being restored.
- Startup no longer waits for the sound archive or user scripts before showing the usable client interface. Sound loading begins in the background after its first frame, scripts follow without extending the startup screen, and startup activity now describes the window-and-control phase explicitly.
- Legacy Macro Library discovery now accepts both .mac and .txt files.
- Moved Batch room artwork loading from Quality to Advanced Settings.
- Clarified that Potato GPU mode is for hardware limited to 4096 by 4096 textures; it does not reduce artwork resolution or upscaling quality.
- Increased the minimum docked toolbar width so status text and controls are not clipped.
- Added an internal settings-coverage document describing persisted, session-only, derived, and currently hidden options without adding it to the web help.

Fixes and classic compatibility:
- Reworked live networking to follow classic framing rules: each UDP datagram contains one complete message, while partial TCP headers, payloads, and draw-state records remain pending until complete.
- Structurally valid draw frames are acknowledged even if an optional logical state record is malformed; the bad record is logged and skipped instead of forcing an unnecessary resend.
- Reconnects reset frame acknowledgement, resend, timing, packet-loss, and PNA learning state so measurements from one session cannot leak into the next.
- TCP and UDP handling is serialized with classic TCP priority so both transports cannot update live session state concurrently.
- Live frame timing and script tick waits now follow accepted server frames rather than render FPS, keeping script timing stable with VSync disabled or at high refresh rates.
- Matched the classic 511-byte player-command limit and 1396-byte maximum framed protocol message size.
- Fixed indexed inventory packets being treated as one-based, which could select or update the wrong instance of duplicate items.
- Fixed malformed UDP datagrams contaminating the next packet, short login messages being read before validation, and cancelled artificial-delay waits affecting a later connection.
- Free Demo login now tries the returned demo characters in randomized order when a candidate is already online and reports clearly when every demo slot is occupied.
- Fixed the Players window briefly showing the local character as sharing with themself, and prevented stale self-sharing state from affecting the Sharing count.
- Preserved the measured server frame interval without integer-FPS rounding.

Technical changes:
- Added a classic-network compatibility tracker and expanded regression coverage for reconnects, fragmented and malformed records, exact UDP datagrams, partial TCP streams, PNA feedback and fallback, live clocks, graph scaling, diagnostic rotation, demo retries, movie seeking, moving-sprite bounds, macros, sharing state, settings layout, and toolbar sizing.
