goThoom 55 changes since test54.

Interface:
- The main workspace now always uses tiled panes. Window Layout offers clickable diagrams, with controls to swap sides, put messages above or below the game, and split separate Chat and Console side by side or vertically.
- Combine chat + console is available in Window Layout. Separating messages restores a working Chat pane and input bar.
- Auto-size side panels uses empty space beside the game; turning it off keeps the current divider sizes for manual resizing.
- Fixed pane resizing at screen edges and improved control sizing, alignment, and spacing.
- Combined live stats, command search, Help, and snapshots into the new Tools menu.
- Open Window Layout or Reset Windows from Settings > Display. The setup wizard includes the same clickable layout previews.
- Reduced the minimum width needed for the toolbar in Inventory or Players.
- The title bar now reads `goThoom`, adding the active character name after `--` while logged in.
- About and Changelog now open in a wider, resizable 16:10 layout.
- Status bars now offer Regular, Modern -- thin, and Hidden styles. Modern -- thin is the default, with an optional below-toolbar-hands placement.
- Refreshed the client screenshot in the README and website, and added an Accounts link.
- Expanded the online manual with annotated screenshots, interactive layout diagrams, and dedicated automation and performance guides. Each update lists the relevant game version and date.

Macros and scripts:
- Legacy macro rows now offer Commands and Keybinds editors for renaming typed triggers and recording replacement keys, clicks, or wheel gestures. Edits preserve comments and macro bodies and check for conflicting triggers before saving.
- Legacy macros distinguish Backspace (delete) from forward Delete (del) and recognize classic keypad Enter and Clear bindings.
- Fixed legacy right-click macro compatibility with the classic Mac client, including Control-click bindings in the game and Players list.
- Go scripts request permissions before their first use. Review or change access to commands, keybinds, server commands, and other capabilities from the script's Permissions button.
- Expanded Go scripting with world data, events, movement controls, and script-created windows and controls. Updated the API reference and editor support.
- Script information windows keep their action buttons visible below the scrolling details.

Settings and setup:
- Added a Show FPS option in Display, plus separate Autocomplete and Spellcheck options in Text.
- The Network server setting now opens the existing Server List editor.
- Expanded NLSPT as Network Latency & Server Phase Timing in both Settings and Live Stats, with its enable/disable control available in either place.
- Graphics detection in the setup wizard now clearly shows that the performance check is in progress.

Audio:
- Text-to-speech now has its own Settings > TTS tab.
- Added a Music SoundFont selector to Settings > Audio for choosing any valid `.sf2` file in Assets & Audio, with a refresh button for newly added files and a direct Audio Settings button in the Mixer.
- Custom SoundFonts may contain only selected instruments; missing Bank 0 presets automatically use the bundled default SoundFont.
- SoundFont changes now take effect during active bard music while staying as close as possible to the current song position.
- Releasing the bard-music enhancement slider after changing it now re-renders active music from the current song position.
- Bard instruments are normalized per SoundFont and instrument program for more consistent perceived volume, with conservative peak protection for chords and groups.
- Disconnecting or logging out now stops active bard music.

Movie playback:
- Bard music is indexed on the `.clmov` timeline, with colored song regions and consistent scrub or jump seeking that resumes at the corresponding song position.
- Bard-music tempo now follows playback UPS without changing instrument pitch.
- Pausing and resuming movie playback now pauses and resumes bard music; Stop pauses playback when no seek is active, and exiting the movie player stops it.
