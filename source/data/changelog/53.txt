goThoom 53 changes since test52.

Connection:
- Added a server selection menu. Built-in servers are always available, and custom host:port entries can be added, selected, and removed from the list.
- Added gothoom.m45sci.xyz:5010 to the built-in server list.
- The -server command-line option can override the server for one launch without changing saved settings.

Login:
- Free Demo now lets you choose from the available demo characters instead of automatically selecting one.
- The login button remains unavailable until a character is selected, preventing accidental login attempts.
- Adding a character whose name already exists now reports an error instead of replacing the saved login.

Chat and interface:
- Fixed speech bubbles after a window resize, display-scale change, or when drawing into an offset viewport.
- Text logs now use the classic Windows client layout: one dated log file directly in each character's Text Logs folder.

Mac:
- The game input supports macOS Dictation and input-method composition.
- Added familiar Mac editing shortcuts: Command for copy, paste, and the command palette; Option for word movement; and Command for line movement and deletion.
- The keyboard tester labels the Command and Option keys as they appear on Mac keyboards.

Documentation:
- Added a searchable reference for image IDs 0 through 99, plus a local exporter for previewing game assets without adding extracted artwork to the repository.
