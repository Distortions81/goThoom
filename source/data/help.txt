Movement
--------
- Left-click to walk toward the cursor. With "Click-to-Toggle Walk" enabled, one click sets a walk target.

Communication
-------------
- Press Enter to start typing; press Enter again to send.
- Press Esc to cancel; Up/Down browse previous messages.
- While typing: Ctrl-V pastes, Ctrl-C copies the whole line.
- Right-click the input bar for Paste, Copy Line, or Clear Line. Paste and Clear return you to typing mode.
- Right-click a chat or console line to copy it; the line briefly highlights.

UI Navigation
-------------
- Click the "Windows" button on the toolbar to open or close UI windows.
- Click the "Actions" button on the toolbar for hotkeys, shortcuts, or scripts.
- Click the "Audio" button to open the Mixer.
- Click "Palette" or press Ctrl-Shift-P to search settings, windows, scripts, player actions, and commands. Type to filter, use Up/Down to select, and press Enter to run.
- Mouse wheel scrolls lists and text windows.
- Window positions, sizes, and open/closed state persist between runs.
- Sliders: hold Shift to snap to integers; hold Ctrl for fine adjustment at 1/8 speed.
- UI Scale is available under Settings → Window & Display. Automatic HiDPI scaling follows the display scale.

Tiled Window Mode
-----------------
- Tiled window mode is enabled by default. The Game fills the center, Inventory is on the left, and Players is on the right.
- Chat and Console output are combined in the Console by default. The Console uses the lower-left tile; if separated, Chat uses the lower-right tile.
- Drag a visible divider to resize adjacent tiles. With "Keep game window large" enabled, dragging either side of the Game moves the fixed-size Game pane and both dividers together.
- Open Settings → Window & Display → Tiled Layout to choose the layout, swap Inventory and Players, swap Console and Chat, combine their output, or choose which side holds the Game in the alternate layout.
- The toolbar stays inside Inventory or Players in tiled mode. Utility windows outside the main tile set remain normal movable windows.
- Turn off "Tiled window mode" in Settings to return the main windows to freeform movement and resizing.

Chat & Console
--------------
- Chat and Console are combined by default. Change "Combine chat + console" in the Tiled Layout window to show separate tiles.
- The input bar auto-expands as you type. Use the right-click menu for paste, copy, or clear.
- Messages with `@<your name>` or `@<profession>` highlight in blue and play a tink sound.

Players
-------
- The Players window lists nearby or known exiles. The header shows an Online count and share status summary when relevant.
- Tags: ">" means sharing, "<" means sharee, "*" marks same clan.
- Single-click selects a player.
- Right-click a player for actions: Thank, Curse, Anon Thank…, Anon Curse…, Share, Unshare, Info, Pull, or Push.

Inventory
---------
- Single-click selects an item.
- Double-click equips or unequips an item. Shift + double-click uses an item.
- Right-click an item for a context menu: Equip/Unequip, Examine, Show, Drop, or Drop (Mine).
- If an item has a shortcut, its key appears in brackets before the name (e.g., "[Q]").

Other Windows
-------------
- Help: this guide (Windows → Help).
- Hotkeys: configure built-in and script hotkeys.
- Shortcuts: define text expansions for the input bar.
- Triggers: view script trigger phrases.
- Audio/Mixer: adjust overall, game, music, TTS, and notification volumes; toggle channels and audio enhancement.
- Settings/Quality: tweak the window layout, UI scale, visuals, sound, notifications, and presets.

Extras
------
- Custom background: place `background.png` in the `data/` directory.
- Music test: `/play <instrument-number> <notes>` (e.g., `/play 10 cdefg`).
- Settings commands: `/setting search <text>`, `/setting get <name>`, `/setting set <name> <value>`, and `/setting reset <name>`.

Low-end Hardware
----------------
For very old computers or single-board computers such as Raspberry Pi, "Potato GPU (Low VRAM)" under Quality Settings can use unmanaged textures. It defaults off; enable it only if needed.
