The SVG sources are white masks with black outlines. Run `render.sh` to render
every source directly to a 64 by 64 PNG with librsvg/Cairo antialiasing. This
uses no intermediate raster resize. The outline is two pixels in the PNG and
approximately one pixel when the icon is drawn at 32 pixels.
