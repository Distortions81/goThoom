# Material Symbols

The movie-control icons in this directory come from Google's Material Symbols
Rounded set:

- `replay_30`
- `replay_5`
- `play_arrow`
- `pause`
- `forward_5`
- `forward_30`
- `stop`
- `speed_0_5x`
- `shutter_speed_minus`
- `speed`
- `shutter_speed_add`
- `speed_2x`
- `exit_to_app`
- `fast_rewind`
- `arrow_left`
- `arrow_right`
- `fast_forward`
- `fast_rewind_3` (goThoom triple-arrow variant)
- `fast_forward_3` (goThoom triple-arrow variant)

Source: https://github.com/google/material-design-icons

License: Apache License 2.0
https://www.apache.org/licenses/LICENSE-2.0

The SVG sources were changed to white masks with black outlines and rasterized
to 64-pixel (2x) PNGs so goThoom can tint them with the active UI theme. The
outline is two pixels at source resolution and approximately one pixel when
the icon is drawn at 32 pixels.
